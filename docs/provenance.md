# Provenance and distribution scope

This implementation, executable skill, fictional task-board fixture, evaluator and tests were created together for this project. No proprietary source library was accessed or copied into the package. The knowledge base and task reports describe the fictional board, not private customer or production records.

The two regression JSON fixtures in `tests/fixtures/` retain invalid v0.1 plan-response text and v0.2 assessment requests/responses from this project's fictional development cases. They are regression examples, not evidence that a mocked test is a live model run. Runtime dependencies and model weights are not bundled. Playwright, Chrome/Chromium, Node.js, Python, Ollama and any selected model remain subject to their own licenses and operating requirements.

The existing original-source MIT license is retained. This statement records development provenance and distribution scope; it is not an independent legal opinion or a warranty of fitness for a production system.

This repository contains the verified v0.3 runtime, source tests, portable example configurations and documentation. It excludes browser profiles, credentials, production data, full local run directories, screenshots, local transfer records, personal machine paths and completed human-review labels. The private repository visibility is not a reason to commit those excluded artifacts later.

The current application-level controller protects a narrow fictional workflow. Agent and oracle processes share an OS user, and trusted executable paths are operator-controlled. Do not treat the fixture separation, content hashes or original implementation as a hostile-code isolation guarantee.
