# Provenance and distribution scope

The original implementation, operator skills, fictional fixtures, evaluator and tests were developed together for this project. No proprietary source library was accessed or copied into the package. The reports and knowledge base describe disposable fictional task-board, search and quantity-validation applications, not private customer or production records.

This package preserves the v0.3 task-board runtime and adds the v0.4 reusable controlled-fixture prototype. The final bundle contains the exact rc4 runtime, tests, evaluator and fixtures, with documentation-only additions describing the completed evaluation. See `final-validation.md` for the frozen-source hash, final outcome, provenance and limits. Documentation is not evidence that a mocked test was a live run.

## Regression data

The JSON files in `tests/fixtures/` include invalid v0.1 planning outputs, v0.2 assessment requests/responses, and actual rc2/rc3 local-model decision outputs from this project's fictional development trials. The later fixtures retain 24 rc2 and 58 rc3 replies with source-artifact identifiers and minimal contract metadata. They are model-generated regression records, not newly authored answers, independent holdout cases, or fresh live-model results. The original unsuccessful trials remain failures; replaying their outputs tests validation behavior only.

## Dependencies and license

Runtime dependencies and model weights are not bundled. Playwright, Chrome/Chromium, Node.js, Python, Ollama and the selected model remain subject to their own licenses and operating requirements. The original-source MIT license is retained. This statement records development provenance and distribution scope; it is not an independent legal opinion or a warranty of fitness for production.

## Excluded material and trust boundary

The distributable source bundle excludes browser profiles, credentials, production data, complete local run directories, screenshots, local configurations, transfer records, personal machine paths and completed human-review labels. Raw evaluation evidence is retained separately. Screenshot files were kept on the execution machine and explicitly omitted from the text-only verification transfer; that transfer alone cannot establish screenshot pixel semantics or rehash omitted PNG bytes.

Repository visibility does not authorize adding excluded artifacts. Review content before any later publication. The final package was prepared for the user; no repository push, merge or deployment is implied by packaging.

The controller provides application-level controls for authorized disposable loopback fixtures. Agent and oracle processes share an OS user, and executable/module paths are operator-controlled. The operator also defines the capabilities, probes and expected requirements. Do not treat routing, content hashes, fixture separation or code originality as hostile-code isolation, complete egress control, autonomous permission checking, or a guarantee that the test specification matches a real bug.
